1. 第三课 杂化轨道与碳的四价本质（第 3 天）

1.1. 课前信息

  • 课程进度: 阶段一·基础筑基（第 3 天）
  • 本课主题: 原子轨道 → 填充规则 → 激发与杂化 → sp³ 与烷烃
  • 课堂提问: 4 问全对
  • 课后练习: 6 题对 5 题, 错题第 4 题（σ 键特点）
  • 打卡状态: 已完成

1.2. 小结一: 原子轨道——电子的"家"

  1. 1. 原子轨道的本质
    • 电子不是像行星绕太阳那样沿固定圆圈转
    • 电子在核外各处出现的概率不同, 最常出现的区域称为原子轨道（也叫电子云）
    • 本课只需要掌握两类轨道: s 轨道、p 轨道
  2. 2. s 轨道
    • 形状: 球形（像篮球, 原子核在球心）
    • 容量: 每个 s 轨道最多 2 个电子
    • 关键: 这 2 个电子必须自旋相反（一个"上旋"一个"下旋"）
  3. 3. p 轨道
    • 形状: 哑铃形（像两个对扣的勺子）
    • 方向: 沿坐标轴有 3 个方向, 记作 px、py、pz
    • 容量: 每个方向最多 2 个电子 → p 轨道总共最多装 6 个电子
    • 简图: s 轨道 ○, p 轨道 ∞
  4. 4. 碳的基态电子排布
    • 轨道式: 1s² 2s² 2p²
    • 解读: 1s 满 2 个, 2s 满 2 个, 2p 三个方向中只有 2 个方向各装 1 个电子
    • 未成对电子数: 2 个（都在 2p 里）
  5. 5. 成对与未成对（核心概念）
    • 成对电子: 同一轨道里两个自旋相反的电子
    • 未成对电子: 一个轨道里孤零零只有 1 个电子
    • 意义: 未成对电子的数目决定了该原子能连几根键（每根键需要一个未成对电子）

1.3. 小结二: 电子填轨道的三条铁规矩

  1. 1. 能量最低原理
    • 电子先占能量低的轨道
    • 能量顺序: 1s < 2s < 2p < 3s < 3p …
    • 先填满 1s, 再填 2s, 最后才轮得到 2p
  2. 2. 泡利不相容原理
    • 每个轨道最多 2 个电子
    • 且这 2 个电子必须自旋相反
  3. 3. 洪特规则
    • 同一层的轨道（如 3 个 2p 轨道）电子先一个一个单独坐
    • 每个轨道先各占 1 个, 都各有一个后才开始成对
    • 比喻: 公交车空位多时, 人都喜欢一人一个座位不挤
  4. 4. 验证与例题
    • 碳 C（6号）: 1s² 2s² 2p² → 2p 两个电子分占两个轨道 → 2 个未成对电子
    • 氮 N（7号）: 1s² 2s² 2p³ → 3 个电子各占一个 2p 轨道 → 3 个未成对电子
    • 规律: 未成对电子数 = 半充满前同一亚层独立占据的轨道数
  5. 5. 为什么电子要"单着来"
    • 电子都带负电, 互相排斥
    • 能分开坐就不挤在一起（这是洪特规则的物理本质）

1.4. 小结三: 碳从"2 根键"变成"4 根键"的两步走

  1. 1. 矛盾的提出
    • 碳基态只有 2 个未成对电子, 按常理只能连 2 根键
    • 但甲烷 CH₄ 里碳连着 4 根一模一样的 C—H 键, 键角都是 109.5°
    • 矛盾必须靠激发 + 杂化解决
  2. 2. 第一步: 激发（Promotion）
    • 碳把 2s 轨道里的 1 个电子"踢"到空的 2p 轨道上
    • 激发后排布: 1s² 2s¹ 2p³
    • 结果: 有了 4 个未成对电子, 可以连 4 根键
    • 代价: 能量升高, 但成键释放的能量能赚回来
  3. 3. 第二步: 杂化（Hybridization）
    • 1 个 2s + 3 个 2p 轨道不再各自独立, 而是混合重组
    • 像不同颜色的颜料混在一起, 变成 4 个完全一样的新轨道
    • 新轨道名称: sp³ 杂化轨道
  4. 4. sp³ 杂化的关键特征（必须背熟）
    项目 内容
    杂化来源 1 个 s + 3 个 p
    生成轨道数 4 个等价 sp³ 轨道
    空间构型 正四面体
    键角 109.5°
    典型代表 甲烷 CH₄、所有烷烃
    命名由来 sp³ = 1 个 s 轨道 + 3 个 p 轨道
  5. 5. 空间理解
    • 4 个 sp³ 轨道为了互相离得最远, 自然形成正四面体
    • 示意图: 碳在中心, 4 个 H 指向正四面体的 4 个顶点
    • 所有只有单键的碳（乙烷、丙烷、丁烷）全是 sp³

1.5. 小结四: sp³ 杂化的实战——烷烃世界与 σ 键

  1. 1. 核心规律
    • 只要碳只连单键（C—C、C—H）, 它就是 sp³ 杂化, 键角约 109.5°
    • 有机化学里绝大多数分子骨架是碳链/碳环, 上面的碳几乎全是 sp³
    • 掌握 sp³ 就掌握了有机分子的"骨架语言"
  2. 2. 烷烃家族示例
    分子 碳的杂化 键角 结构特征
    CH₄ sp³ 109.5° 正四面体
    C₂H₆ sp³ ~109.5° 两个四面体共用一个顶点
    C₃H₈ sp³ ~109.5° 链状排列
  3. 3. σ 键（sigma 键）——第一个成键类型
    • 定义: sp³ 轨道头碰头重叠形成的共价键
    • 特点 1: 电子云沿键轴对称分布
    • 特点 2: 电子云集中在两核之间（头碰头重叠的必然结果）
    • 特点 3: 可以绕键轴自由旋转（乙烷能像拧麻花一样旋转）
    • 特点 4: 存在于一切共价键中
      • 单键 = 1 个 σ 键
      • 双键 = 1σ + 1π（π 键后课再学）
      • 三键 = 1σ + 2π
  4. 4. 今日易错点（重点标记）
    • σ 键不是"只能存在于双键中"——它存在于所有共价键里!
    • 电子云集中在两核之间恰恰是 σ 键的核心特征, 不是错误项

1.6. 本课记忆清单（明日抽查）

  • 电负性主序: F > O > Cl > N > C > H（氯比氮大, 氢垫底）
  • 碳基态 2 个未成对电子, 氮基态 3 个
  • sp³: 1s+3p → 4 个等价轨道, 正四面体, 109.5°
  • 激发在前, 杂化在后: 先 2s¹2p³ 再混成 4 个 sp³
  • σ 键: 头碰头、轴对称、可旋转、存在于一切共价键

  • 主题: sp² 与 sp 杂化（烯烃、炔烃）, 不饱和烃世界
  • 重点: 双键 = 1σ + 1π, 三键 = 1σ + 2π, 键角 120°/180°
